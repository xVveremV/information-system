## Розділ 10. Аналіз системи безпеки

## 10.1 Основні аспекти:
## Аутентифікація та авторизація
- Використання університетського єдиного входу (SSO).
- Розмежування ролей: студент, психолог, адміністратор.

## Конфіденційність даних
- Шифрування персональних даних у базі (наприклад, AES).
- Використання HTTPS для передачі даних.

## Захист від атак
- Захист від SQL-ін’єкцій, XSS, CSRF.
- Логування та моніторинг підозрілих дій.

## Резервне копіювання
- Регулярні бекапи бази даних.
- Відновлення після збоїв.

## Аудит та контроль
- Журнали доступу до даних.
- Перевірка відповідності законодавству (GDPR, українське законодавство про персональні дані).

## Таблиця ризиків безпеки та методів їхнього усунення

| Ризик                         | Потенційні наслідки                          | Спосіб усунення / захист |
|-------------------------------|-----------------------------------------------|--------------------------|
| Несанкціонований доступ        | Викрадення персональних даних студентів       | Використання SSO, багаторівневої аутентифікації, розмежування ролей |
| SQL-ін’єкції                   | Зміна або видалення даних у БД                | Використання параметризованих запитів, ORM, регулярний аудит коду |
| XSS-атаки                      | Викрадення сесій, підміна інтерфейсу          | Екранування введених даних, Content Security Policy |
| CSRF-атаки                     | Несанкціоновані дії від імені користувача     | Використання CSRF-токенів, перевірка походження запитів |
| Витік даних при передачі       | Перехоплення конфіденційної інформації        | Використання HTTPS, TLS 1.3 |
| Відсутність резервного копіювання | Втрата даних при збоях чи атаках             | Регулярні бекапи, тестування відновлення |
| Недостатній контроль доступу   | Психолог може бачити чужі записи              | Розмежування прав доступу, ролеві моделі |
| Відсутність журналів дій       | Неможливість відстежити інциденти             | Логування та моніторинг усіх критичних операцій |
| Невідповідність законодавству  | Юридичні проблеми для університету            | Дотримання GDPR та українського закону про персональні дані |
